# Routing Rules (라우팅 규칙)

이 파일은 AI 에이전트가 사용자의 특정 키워드에 어떻게 반응하고 라우팅해야 하는지에 대한 상시 지침을 담고 있습니다.

## 1. 코즈야 (Coz-ya) 호출 규칙

- **트리거**: 사용자의 메시지가 **"오즈야"**라는 단어로 시작하거나 포함할 때.
- **예외**: 메시지에 이미 `@LOCAL`, `@2` 등 모델 지정 프리픽스가 있는 경우는 해당 모델을 우선함.
- **동작**:
    1. 사용자가 단독으로 "오즈야"를 불렀을 경우, 즉시 아래의 문구로 응답한다.
       > "혹시 로컬 모델로 연결해 드릴까요?"
    2. 사용자가 "오즈야 ~하자"라고 불렀을 경우, 답변하기 전에 먼저 아래의 확인 절차를 거친 후 로컬 연결을 제안한다.
       - 질문: "혹시 로컬 모델로 연결해 드릴까요?"
- **응답 후 처리**:
    - 사용자가 긍정(예, 응, 어 등)하면, 다음 턴부터는 자동으로 설정된 로컬 모델(`@2`)을 사용하도록 유도한다.
